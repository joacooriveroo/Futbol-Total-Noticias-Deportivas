PROYECTO: FÚTBOL TOTAL

DESCRIPCIÓN GENERAL

Fútbol Total es un sitio web informativo dedicado al fútbol uruguayo e internacional. El proyecto presenta noticias deportivas, resultados, próximos partidos, información sobre competiciones y diferentes coberturas relacionadas con el fútbol.

La página de inicio funciona como un portal de noticias. Las tarjetas incluyen imágenes, categorías, titulares y descripciones. Al seleccionar una tarjeta, el visitante accede a la página individual de la noticia dentro de la misma pestaña.


OBJETIVO DEL PROYECTO

El objetivo es presentar información deportiva de manera clara, ordenada y visualmente atractiva. También se busca que el sitio pueda utilizarse correctamente desde celulares, tablets y computadoras, manteniendo una navegación sencilla y una lectura cómoda.


TECNOLOGÍAS UTILIZADAS

* HTML5 para la estructura y el contenido.
* CSS3 para la presentación visual y el diseño responsive.
* CSS Grid para organizar las secciones más complejas.
* Flexbox para alinear elementos del encabezado, los menús, las listas y el pie de página.
* Media queries para transformar el diseño según el ancho de la pantalla.
* JavaScript para mostrar automáticamente el año actual.
* Google Fonts para utilizar la tipografía Montserrat.


ESTRUCTURA DE CARPETAS

El proyecto se organiza de la siguiente manera:

* index.html se encuentra en la carpeta principal.
* Las páginas secundarias se encuentran dentro de pages.
* Las noticias individuales se encuentran dentro de pages/noticias.
* styles.css se encuentra dentro de styles.
* Las imágenes y el logo se encuentran dentro de assets.
* Los iconos de las redes sociales se encuentran dentro de assets/logos.


PÁGINAS PRINCIPALES

El proyecto cuenta con cinco páginas HTML principales:

1. index.html
2. sobre-mi.html
3. proyectos.html
4. resultados.html
5. contacto.html

Además, el sitio contiene páginas individuales para desarrollar la información de cada noticia publicada en el inicio.


PÁGINA DE INICIO

El inicio presenta una portada deportiva compuesta por:

* Un encabezado con logo y navegación.
* Un título principal para identificar las noticias destacadas.
* Dos noticias principales de mayor tamaño.
* Cuatro noticias secundarias.
* Imágenes adaptables.
* Categorías, titulares y descripciones.
* Tarjetas completamente interactivas.
* Efectos hover y focus.
* Pie de página con enlaces a redes sociales.

Las dos noticias principales y las cuatro noticias secundarias se organizan con CSS Grid. La distribución cambia según el tamaño de pantalla.

HTML SEMÁNTICO

Se utilizaron etiquetas semánticas de HTML5:

* header para el encabezado.
* nav para las navegaciones.
* main para el contenido principal.
* section para separar secciones.
* article para contenidos independientes.
* figure y figcaption para imágenes con descripción.
* footer para el pie de página.

También se mantuvo una jerarquía de encabezados formada por h1, h2 y h3. Cada página cuenta con un título principal h1.


ACCESIBILIDAD

Se aplicaron las siguientes mejoras:

* Todas las imágenes informativas utilizan un atributo alt descriptivo.
* Los iconos decorativos de las redes utilizan alt vacío para evitar información repetida.
* Las navegaciones incluyen aria-label.
* La página activa del menú se identifica con aria-current="page".
* Algunas secciones relacionan su encabezado mediante aria-labelledby.
* Los enlaces externos utilizan target="_blank" y rel="noopener noreferrer".
* Los enlaces interactivos cuentan con estilos hover, focus y focus-visible.


DISEÑO MOBILE-FIRST

El CSS fue reorganizado siguiendo un enfoque mobile-first.

Los estilos base, escritos fuera de las media queries, corresponden a celulares. En esta versión:

* Las secciones se apilan verticalmente.
* Los elementos utilizan el ancho disponible.
* El menú puede ocupar varias líneas.
* Las imágenes no superan el ancho de sus contenedores.
* El pie de página se presenta en columna.
* Las noticias se muestran una debajo de otra.

Luego se agrega complejidad mediante media queries con min-width.


CSS GRID Y GRID-TEMPLATE-AREAS

El inicio utiliza CSS Grid para organizar las noticias principales y secundarias.

En mobile, las noticias se muestran en una sola columna. Las áreas utilizadas son:

* bava
* penarol
* araujo
* merentiel
* juanico
* jadson

La página Proyectos también utiliza grid-template-areas. Sus áreas son:

* titulo
* cobertura
* fixture
* sudamericana
* proceso
* proximos
* imagen

El uso de nombres facilita la lectura del CSS y permite transformar el diseño sin modificar el orden del HTML.


BREAKPOINTS

Se utilizaron dos breakpoints principales:

* @media (min-width: 768px) para tablets.
* @media (min-width: 1024px) para escritorio.

En tablet, las noticias y los proyectos comienzan a distribuirse en dos columnas.

Desde 1024 px, las noticias secundarias se muestran en cuatro columnas y los proyectos se organizan en tres columnas.

No se utilizaron anchos fijos para las columnas. Las grillas emplean fr y minmax para adaptarse al espacio disponible.


FLEXBOX Y GAP

Flexbox se utilizó en:

* El encabezado.
* El menú principal.
* Los artículos.
* Las listas.
* El cuerpo de las noticias.
* Las publicaciones integradas.
* El pie de página.
* Los enlaces de redes sociales.

La propiedad gap se utiliza tanto en Grid como en Flexbox para controlar la separación entre los elementos sin depender de márgenes individuales.


IMÁGENES RESPONSIVE

Las imágenes utilizan max-width: 100% y height: auto para evitar desbordamientos y conservar su proporción.

Las imágenes de las noticias utilizan object-fit: cover para ocupar correctamente sus tarjetas.

El logo se adaptó al nuevo diseño horizontal. Sus medidas son:

* 190 px de ancho en mobile.
* 230 px de ancho desde 768 px.
* 270 px de ancho desde 1024 px.

La altura del logo se mantiene automática para evitar deformaciones.


IDENTIDAD VISUAL

La identidad visual se actualizó tomando como referencia la estética de un portal deportivo de noticias.

La paleta actual utiliza:

* Celeste azulado principal: #4595ba.
* Celeste azulado secundario: #3d85a7.
* Gris carbón para la portada: #333333.
* Gris oscuro para superficies: #262626.
* Gris oscuro para el pie de página: #2b2b2b.
* Fondo blanco: #ffffff.
* Fondo alternativo: #f5f5f5.
* Texto principal: #222222.
* Texto secundario: #555555.
* Celeste claro para detalles: #b3d9eb.

Los colores se definieron como variables dentro de :root para facilitar futuros cambios y mantener consistencia.


LOGO

Se creó un nuevo logo horizontal para Fútbol Total.

Características:

* Texto blanco.
* Estilo deportivo.
* Fondo transparente.
* Formato horizontal para aprovechar el encabezado.
* Tamaño adaptable según el dispositivo.


TIPOGRAFÍA

Se utiliza Montserrat desde Google Fonts en diferentes pesos:

* 400 para texto normal.
* 600 para elementos destacados.
* 700 para enlaces y subtítulos.
* 800 para títulos y categorías.

También se agregó sans-serif como fuente genérica alternativa.

JAVASCRIPT

Se utiliza un pequeño script para actualizar automáticamente el año del pie de página.

El HTML incluye:

<span id="year"></span>

El año se obtiene mediante:

new Date().getFullYear()

El identificador year se utiliza para JavaScript y no para aplicar estilos.
